# Data

Raw datasets are large and are **not committed** to this repository.

## MIT/Stanford battery cycle-life dataset

1. Download the batch files from https://data.matr.io/1 (or a mirrored copy, e.g. on Kaggle).
2. Place them in `data/raw/`.
3. Run the processing scripts in `model/` to produce feature files in `data/processed/`.

Citation: Severson, K. A. et al. *Data-driven prediction of battery cycle life before capacity degradation.* Nature Energy 4, 383–391 (2019).
